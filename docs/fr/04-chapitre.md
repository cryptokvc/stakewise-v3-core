# 4. Sortie et sécurité

Les retraits doivent composer avec les délais du protocole et la liquidité disponible. Les rôles, les upgrades et le slashing constituent les principales limites de confiance.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
