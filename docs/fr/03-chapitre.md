# 3. Opérateurs et validators

Les opérateurs exécutent les tâches de consensus tandis que le vault garde la comptabilité. Les limites de clé, de retrait et de performance réduisent le risque opérationnel.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
